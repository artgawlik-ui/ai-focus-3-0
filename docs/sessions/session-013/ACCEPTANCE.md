# Kryteria 013

- Wybór niejednoznacznej miejscowości przed wyszukiwaniem w promieniu 1–50 km.
- Wyniki OSM z odległością, źródłem i datą; brak fikcyjnych danych i automatycznego CRM/DM.
- Cache i limit publicznej geokodacji; brak autocomplete, osobne kliknięcie użytkownika.
- Walidacja współrzędnych/promienia, odporność na błędne dane, duplikaty OSM i awarie.
- Zachowane stare wyszukiwanie miasta; nowe funkcje za flagą domyślnie OFF.
- Frontend mobilny, testy mock HTTP/API i końcowe CI; brak produkcyjnych zmian/kosztów.
